# Pera nai Vai 🎨

A free, privacy-first image and design tool suite built for everyone — especially users in Bangladesh.

---

## What is Pera nai Vai?

**Pera nai Vai** is a web-based creative toolkit with 15+ tools for image editing, design, and more — all running **locally in your browser**. No uploads, no accounts, no data sent to any server.

> Built for 4.2M+ users in Bangladesh, but open for anyone around the world.

---

## ✨ Features

- 🛠️ **15+ Tools** — image editing, design utilities, and more
- 🔒 **100% Local Processing** — your files never leave your device
- ⚡ **Fast** — loads in under 2 seconds
- 📱 **PWA Support** — install it like an app on your phone
- 🌐 **Works Offline** — no internet needed after first load
- 🇧🇩 **Bengali Localization** — built with local users in mind

---

## 🚀 Getting Started

1. Visit the app in your browser
2. Pick any tool from the suite
3. Upload your file — it stays on your device
4. Edit, export, done!

No sign-up required.
